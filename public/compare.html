Root-cause guide

How conclusions are made

All aligned: staging, production host, and CDN match.

CDN stale: production host has the new release, but CDN does not.

Not deployed: staging is new, but the production host is still old.

Production differs: host and CDN agree but intentionally or unexpectedly differ from staging.

Release IDs and expected markers are strongest. Static-file hashes are strong. Normalized HTML and cache headers are supporting evidence.
