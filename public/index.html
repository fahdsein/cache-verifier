Is your CDN serving the newest content?

Check pages and discovered assets from the server, inspect cache headers, and compare a normal response with a cache-bypassed probe. Add an expected text marker for the strongest freshness result.

How it works
  1. Request the public URL normally.
  2. Request it again with a unique query and no-cache headers.
  3. Compare content hashes, markers, cache state, age, and TTL.

Interpretation

A cache HIT does not mean stale

Current: expected newest text exists in the normal response.

Stale: expected text exists only in the bypassed response.

Review: hashes differ, the marker is absent, or headers cannot prove freshness.

Consistent: both probes have the same hash, but no marker was supplied.
